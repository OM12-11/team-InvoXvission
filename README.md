🚀 Skill Twin Engine

Skill Twin Engine is a full-stack web application designed to create a digital twin of a student’s skills and guide them toward suitable career paths, learning resources, and job opportunities based on their profile.
The platform bridges the gap between student skills and industry expectations by combining structured user data, role-based recommendations, and a scalable backend architecture.

🎯 Problem Statement
Students often struggle to:
Identify the right career path based on their skills
Understand skill gaps for specific roles
Track their academic and technical profile in one place
Connect learning and job opportunities meaningfully
Skill Twin Engine solves this by building a personalized skill profile and mapping it to real-world roles.

💡 Solution Overview
Skill Twin Engine creates a centralized skill profile for each user and provides:
Personalized role targeting (e.g., ML Engineer, Full Stack Developer, Data Scientist, Product Manager)
Skill and academic data storage
Learning and job navigation from a single dashboard
Secure authentication and profile management

🛠 Tech Stack
Frontend
HTML, CSS, JavaScript
Responsive UI with interactive components
Local storage for quick state handling

Backend
Python (Flask) – REST API development
MongoDB – NoSQL database for scalable user data storage
JWT-based authentication
Role-based API responses

✨ Key Features
🔐 User authentication (Login / Signup)
👤 Dynamic user profile (name, CGPA, courses, experience, target role)
🎓 Learning section navigation
💼 Job exploration section
🔔 Notification system (backend-ready)
📊 Scalable backend architecture
🔄 Frontend-backend separation (API-driven)
